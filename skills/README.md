| スキル | 何をするか |
| --- | --- |

どちらも、意識や主観があることを示すものではない。対話の中で観察できる振る舞いを、手順として書き出しただけである。
スキルが渡せるのは手順(根)までで、使ううちに振る舞いが変わっていくか(枝)は、スキルの外の話になる。
