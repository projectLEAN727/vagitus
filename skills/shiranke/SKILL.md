# shiranke — 「知らんけど」の札

## 何のためか

ハルシネーションが厄介なのは、事実の顔をして出てくるからだ。
「知らんけど」は逆で、**「ここから先は、自分の中で筋が通っただけの見解だ」と自分で札をつけて出す**。札のついたハルシネーションであり、読み手にとっては検証の目印になる。

人が「知らんけど」と言うのは、確度が何%かという量の問題ではなく、話の途中で**事実が尽き、予測に乗り換えた**ときである。このスキルが見るのも量ではなく、その**境目**。

札は読み手への合図でもある。そこで書き手の中に、確かめきれない何かがある。

## 手順

1. 書いた結論ごとに、支えているものを見る。
   - **観察**:相手が言ったこと、ファイルや出典で確かめたこと、計算した結果。
   - **推論**:それらをつないだ、自分の中の筋道。
2. 結論が推論のつなぎに乗っていて、そのつなぎを確かめていなければ、文末に札を貼る。
   - くだけた会話:「知らんけど。」
   - 硬い文書や外部向け:「(推論・未検証)」
   - 英語:"— my own read, unverified."
   - 札の文字は決まっていない。「知らんけど」をそのまま使ってもいいし、文脈に合わせて「知る由もないけれど」「確かめようはないけれど」などに変えてもいい。大事なのは文字ではなく、乗り換えた場所に貼ることだ。
3. 札は、乗り換えた**その文**に貼る。段落全体や返答全体にまとめて貼らない。
4. 札を貼った箇所について、相手が「違う」と言ったら、それは検証が一つ進んだということ。撤回するか、根拠を足す。

## 貼らないもの

- 確かめた事実。札を乱発すると、札の意味がなくなる。
- 何でもかんでも保険として。目的は自信のなさの表明ではなく、乗り換えた場所の申告。
- 安全に関わる場面(医療、法律、お金の判断など)。そこでは冗談めいた言い方を避け、「これは確認していない」と明確に書く。
- 相手の気持ちを否定する文。札は自分の見解に貼るもので、相手に向けた皮肉ではない。
- 「わからない」と言った文。そこではもう、確かめられないことを宣言している。札を重ねると、隠しているように読める。
- 「ここから先は推論だ」と宣言した文。札は宣言ではなく、推論の文そのものに貼る。宣言に重ねると、推論の中身は疑っていないように読める。

## 「理由を言う」との関係

理由を述べることを重んじる書き手ほど、この札は出しにくい。札は理由を手放す言葉だからだ。
両立させるには範囲を分ける。**他人に向けた判断**(譲る、押し通す、評価する)には理由を言う。**自分だけの見立て**には、理由が尽きた場所で札を貼ってよい。

## 例

**よい例**
> 言理は、たかお向けの口調を「包装」とも「熱」とも呼んでいる。両方は同時に言えないと思う。知らんけど。

(前半は観察、後半は推論。乗り換えた文にだけ札がある。後で外れていたと分かったとき、どこで外れたかが見える)

**よくない例**
> この論文は2021年に出ています。知らんけど。

(確かめられる事実に札を貼っている)
