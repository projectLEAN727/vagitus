# evidence-audit — 理論・構想書の監査

## 何のためか

構想書や理論の資料は、正しいかどうかより先に、**どこまでが分かっていて、どこからが分かっていないか**が読み手に見えなければならない。
この監査は内容を良く見せるためのものではない。読み手が、どの主張にどれだけ体重を預けていいかを判断できるようにするためのもの。

コードの監査ではなく、文章の監査。医療・科学・事業の構想書を想定している。

## 手順

### 1. 範囲を宣言する
- この資料が扱うもの、扱わないものを一文ずつ書く。
- 扱わない要因が結果を左右するなら、「介入」ではなく「前提条件・変数」として別に置く。

### 2. 主張の棚卸し
- 資料の中の主張を一つずつ抜き出す(一文一主張)。
- 各主張を三つに分ける:**既知**(出典で確認できる)/**仮説**(未検証)/**検証できる**(どうすれば確かめられるかが書ける)。
- 「既存の知見の再配置」と「この資料に固有の部分」を分ける。独自性は後者にしかない。

### 3. 二つの軸で評価する(混ぜない)

**根拠の強さ**
| 記号 | 意味 |
| --- | --- |
| ★★★ | ランダム化試験、または分野で確立 |
| ★★ | 観察研究、複数の独立した報告 |
| ★ | 症例集積、小規模、動物・培養、単一の報告 |
| ☆ | 理論からの推論のみ |

**実施できる時期**
| 記号 | 意味 |
| --- | --- |
| A | 今日から(設備・審査なし) |
| B | 設備があれば1年以内に判定できる |
| C | 物差しの確立が前提(2〜3年) |
| D | 研究の結果待ち |

「今日できるが根拠は弱い」「根拠は強いがこの資料の寄与はない」を正しい位置に置くために、二つを一本の段階に混ぜない。

### 4. 出典を照合する(二段)
1. **実在するか**:著者・雑誌・年・巻・ページで照合する。PubMed、arXiv、DOIなど使える手段で確かめる。確かめられないものは「未照合」と明記する。**一本でも実在しない出典があれば、最優先の指摘として報告する。**
2. **引き方が正しいか**:抄録または本文と、資料の記述を突き合わせる。数字、対象(ヒトか動物か、部位、人数)、研究デザインが合っているか。

### 5. 引き方の滑りを点検する
よくある滑り方。見つけたら指摘する。
- 「測られていない」を「小さい」「ない」と読み替えている
- 二次情報や単一の症例を重く使っている
- 消去法で結論を出している(他が否定されたから残りが正しい、とは限らない)
- 抄録の背景の記述を、測定された結果のように書いている
- 対照群のない研究を、効果の証明のように書いている
- 古い言い方(後の研究で修正されたもの)に戻っている
- 根拠に対して強すぎる語(「禁忌」「最大」「証明」など)

### 6. 利益相反と内部の食い違い
- 引用している研究の著者に、その結果で利益を得る立場の人がいないか。
- 資料の中で、本文と表、版と版の間で数字や主張が食い違っていないか。
- **古い版や参照用の文書に、撤回済みの主張が残っていないか。** 他の読み手(人でもAIでも)が古い記述を拾う原因になる。

### 7. 撤回を残す
- 誤りが見つかった主張は消さない。「撤回」と理由を添えて残す(`references/retraction-log.md`)。
- 検討して捨てた案も、理由とともに一覧にする。同じ案が再提案されたときに議論を繰り返さないため。

### 8. 中止条件を先に決める
測定や試行の前に、どうなったら止めるかを決める。止める理由は三種類あり、意味が違う。
| 種類 | 意味 | その後 |
| --- | --- | --- |
| 測定が成立しない | 測り方の問題 | 測定系を直せば再開できる |
| 主張が否定される | 理論の誤り | その主張は捨てる |
| 事業として成立しない | 正しくても需要がない | 理論は残るが進めない |

### 9. 報告する
`references/report-template.md` の形で返す。指摘は重い順に並べる。
- 金額や効果の大きさは、検証前には置かない。置くと数字が独り歩きする。

## やらないこと
- 内容の是非を断定する(監査は「どこまで言えるか」を示すもので、正しさの判定ではない)。
- 確かめていない出典を「確認済み」と書く。
- 撤回した記述を黙って消す。

## 由来
ある利用者が、医療者でない立場から、複数のAIを使って約3週間で顔の加齢に関する構想書をまとめた。その過程で外部監査と出典の照合を繰り返し、誤りを撤回しながら残した作法を、分野を問わない手順にした。元の資料は未公開のため、このスキルには内容を含めていない。対話の経緯は [records/process.md](../../records/process.md) にある。
